# Mobile-Sales-Analysis-PowerBI.DASHBORAD
Mobile_Sales_Analysis
Identified data fields:
- Brand
- City
- Month
- Mobile Model
- Payment Method
- Year
- Total Price
- Units Sold
- Customer Rating
Project objectives
Sales performance analysis
- Total price aur units sold se related metrics ko visualize karna.
- Brand-wise sales aur units sold compare karna.
- City-wise sales-related information explore karna.
Product analysis
- Mobile models ka comparison karna.
- Brand aur model ke basis par sales patterns dekhna.
- Different products ki performance ko summarize karna.
Customer rating analysis
- Customer ratings ko visualize karna.
- Brand, city aur mobile model ke context mein ratings explore karna.
Payment analysis
- Payment methods ka distribution dekhna.
- Payment method ke basis par sales-related patterns explore karna.
Time-based analysis
- Month aur Year slicers ka use karke selected periods ka data explore karna.
Identified Power BI features
- KPI Cards
- Brand Slicer
- City Slicer
- Month Slicer
- Mobile Model Slicer
- Payment Method Slicer
- Year Slicer
- Column Chart
- Line and Clustered Column Combo Chart
- Line Chart
- Funnel Chart
- Pie Chart
- Table Visual
